Stoppages are rebuilt from the OEE history: the down-time counter rises while the PLC is faulted, so each rise is one stoppage. Faults that follow each other without a running period in between count as one stoppage. The fault code is not stored live yet; it comes from the reader log for the period named in the last column. Stoppages without a note show "not recorded".
